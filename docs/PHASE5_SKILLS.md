# Phase 5 — Skills Spatial Greybox

## Spatial concept

Skills is one continuous architectural capability landscape. Six related structures occupy one shared axis and remain spatially connected by a restrained path system. The current category dominates while neighboring structures remain perceptible. The scene avoids rooms, cards, logos, terminals, progress meters, and one-object-per-technology literalism.

## Taxonomy

The greybox uses the existing terminal filesystem taxonomy without adding inferred skills:

1. **Programming:** DSA, C++, C, Python, Java
2. **Web:** HTML, CSS, Bootstrap, Tailwind CSS, React, MERN Stack
3. **Backend / Database:** Node.js, Express.js, Supabase, MongoDB
4. **Cybersecurity:** Cybersecurity Fundamentals, Network Security, Web Scraping
5. **Tools:** Git, GitHub, Linux, Kali Linux, Ollama
6. **AI Tools:** Antigravity, Claude Code, Lovable, Learnado

Codex does not appear in the verified repository taxonomy and is therefore not displayed. No proficiency ratings, percentages, years, project totals, or unsupported evidence claims are introduced.

## Six structural identities

- **Programming** uses a foundational slab and ordered vertical rhythm.
- **Web** uses overlapping surfaces with open layered depth.
- **Backend / Database** uses linked structures across several depth layers.
- **Cybersecurity** uses controlled boundaries, an opening, and a protected inner volume.
- **Tools** uses supports, beams, and bridging infrastructure.
- **AI Tools** extends the existing structural vocabulary outward, coordinating several levels without using an AI object or neural-network cliché.

All six share the same greybox material and lighting vocabulary. Geometry, spacing, orientation, and scale create their differences.

## Traversal and camera

Native vertical document scroll drives guided lateral and depth travel. Six authored progress centers provide readable pauses rather than equal slide-like segments. The camera uses small elevation changes and keeps neighboring structures visible. It does not orbit, spin, free-fly, or accept game controls.

Desktop fine-pointer movement adds at most a small camera offset. Scroll remains authoritative, pointer input cannot change category or document progress, and coarse/portrait layouts receive no pointer offset. React Three Fiber invalidates only for scroll, resize, or meaningful pointer events; there is no idle animation loop.

## NeuroShield to Skills

NeuroShield's medical meaning, evidence labels, hypotheses, disclosure, and typography retire. A neutral measured axis survives as Skills' first architectural path. That path widens into the Programming foundation and continues through the broader capability landscape. Scene ownership transfers inside the single shared renderer.

## Typography and semantics

Modern grotesk carries monumental category names. Mono carries technology lists and small traversal metadata. All six headings and all 27 skill names exist in semantic HTML; WebGL provides only the spatial environment. Technology names are never baked exclusively into canvas textures.

## Responsive behavior

Desktop shows the current structure with one or more neighboring structures. Portrait uses a wider field of view, compressed horizontal structure spacing, bottom-positioned category typography, smaller list spacing, and no pointer parallax. The complete semantic taxonomy remains present on touch devices.

## Reduced motion and no WebGL

Both modes replace the long traversal with a complete editorial document: one strong Skills introduction followed by six ruled category compositions and every verified skill. They do not mount the shared canvas and do not revive the terminal, LetterGlitch, or MatrixRain.

## Renderer lifecycle and performance

Skills registers with the established `ProjectExperienceProvider`, which selects one active scene among KaiForge, Palindrome, NeuroShield, and Skills. The canvas remains demand-driven with the existing DPR caps. Skills uses primitive boxes, shared color/material vocabulary, fog, one ambient light, one directional light, and one restrained point light. It adds no textures, models, shaders, post-processing, particles, physics, or external assets.

Near the final progress threshold the scene compresses its Z depth and camera movement settles. At the terminal threshold the Skills registration disables itself so the shared renderer unmounts before Achievements owns the viewport.

## Old Skills implementation

`TechnicalSkillsTerminal` is no longer mounted in the primary journey. Its LetterGlitch and MatrixRain children therefore create no hidden canvas or offscreen animation loop. The legacy terminal component, command engine, filesystem, tests, LetterGlitch, and MatrixRain source remain temporarily for an explicit later cleanup rather than being deleted by filename assumption.

## Skills to Achievements exit contract

During the final Skills region, camera travel settles, Z depth compresses, and the continuous path becomes one dominant graphic rule. The shared renderer releases before Achievements begins. A future Achievements greybox may inherit only that flat line/edge as a DOM typographic axis. Skill structures, category labels, and capability meaning retire; Achievements does not appear to solve or rank the Skills world.

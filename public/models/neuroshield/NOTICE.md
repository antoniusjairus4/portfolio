# NeuroShield anatomical brain model

`anatomical-brain.glb` is a derivative of the BodyParts3D anatomical meshes,
copyright The Database Center for Life Science (DBCLS), licensed under
[Creative Commons Attribution-ShareAlike 2.1 Japan](https://dbarchive.biosciencedbc.jp/en/bodyparts3d/lic.html).

Source path: BodyParts3D meshes assembled by the
[brain-game project](https://github.com/Rickaym/brain-game), using meshes from
[anatomy-system](https://github.com/zlatnaspirala/anatomy-system).

Changes for NeuroShield: selected the cortical gyri, white matter, cerebellum,
and brainstem from the assembled model; joined them into six named anatomical
regions plus an internal core; reoriented the model for a lateral view; and
replaced its materials for runtime colouring. Blender was used for this export.
`anatomical-preview.png` is a render of the same derivative model.

The model and preview are offered under CC BY-SA 2.1 JP. The surrounding
portfolio code and content are not part of this model license.

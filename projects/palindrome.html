PALINDROME

Sovereign Financial Intelligence Core & Autonomous Wealth Engine delivering real-time telemetry, local VLM vision parsing, and grounded AI copilot actions.

1. PLATFORM OVERVIEW

Real-Time Financial Telemetry & Autonomous Ingestion

Palindrome is an end-to-end sovereign financial intelligence platform delivering sub-500ms real-time net worth telemetry across multi-asset portfolios including Cryptocurrencies, Equities, Liquid Cash, and Real Estate.

Built with privacy-first client-side OCR (Tesseract.js) and a GPU-accelerated local Vision-Language Model (Ollama/Gemma 2) gateway, Palindrome ingests physical financial documents while guaranteeing zero data leakage to public third-party APIs.

2. HIGH-FREQUENCY TELEMETRY ENGINE

Sub-500ms Real-Time Net Worth Streaming

The core telemetry engine uses Socket.io (initializeAssetStream) to push tick-by-tick portfolio value updates to connected clients every 450ms.

The glassmorphic dashboard integrates GSAP high-frequency animated counters and SVG sparklines for fluid dynamic updates without unnecessary DOM re-renders. It includes global tax liability forecasting across 50+ jurisdictions and real-time asset rebalancing vector math.

3. MALIKETH AI COPILOT

Grounded AI Advisor & Autonomous Queues

Maliketh AI Copilot is a grounded WebSocket-based financial advisor chatbot. It transforms natural language user requests into structured JSON action packets dispatched to background worker threads via Redis and BullMQ queues (e.g. "Log a 50 USD expense for groceries").

By isolating LLM action generation into background queue workers, Maliketh guarantees thread safety, non-blocking UI responsiveness, and instant client-side feedback.

4. HOUSEHOLD LEDGER & AUDIT CHAIN

Cryptographic Audit Chains & Bill Splitting

Features an end-to-end multi-tenant household ledger ("Your House") with HMAC-SHA256 cryptographic chain verification to record every shared transaction immutably.

Includes "Let's Split" for automated multi-user bill splitting, recurring subscription auditing, and shared family balance settlements.

4. DEEP ENGINEERING HIGHLIGHTS

Core Technical Accomplishments

COMPUTER VISION & VLM

Defensive Visual Triage & Local VLM

Two-stage receipt ingestion system. Stage 1 (Triage): Evaluates image blur, legibility, and document authenticity before AI inference to eliminate GPU waste. Stage 2 (Grammar Extraction): Constrains Ollama/Gemma-2 output to strict JSON schema using nucleated sampling (top_p=0.90, top_k=40).

DISTRIBUTED SYSTEMS

Multi-Tier API Failover Matrix

Resilient proxy algorithm maintaining 99.9% uptime against third-party API rate limits. Crypto/Stocks failover: CoinMarketCap → CoinAPI → CryptoAPI → CoinGecko. Currency FX failover: Frankfurter → Fixer.io → ExchangeRate-API → Fallback Matrix.

ASYNC QUEUES & AI

Maliketh Autonomous Action Queues

Natural language queries trigger structured JSON mutation packets. Dispatched to background worker threads via Redis + BullMQ task queues, ensuring thread safety and non-blocking UI operation.

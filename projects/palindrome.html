Palindrome

Real-Time High-Frequency Financial Intelligence Engine & AI Copilot Platform.

High-Frequency Telemetry & Local AI

Palindrome is a full-stack financial telemetry platform built with sub-second WebSocket streaming (450ms refresh cycle) rendering real-time net-worth fluctuations and live asset portfolio valuations across Equities, Cryptocurrencies, and Precious Metals.

Integrated with "Maliketh", a local GPU-accelerated AI copilot utilizing Ollama (Gemma2/Llama3) and MongoDB aggregation pipelines to detect spending anomalies and compute micro-purchase savings recommendations.

Visit Live Platform (palindrome.antoniusjairus.in) ↗

Enterprise Architecture & Security

Built with JWT authentication, cryptographic email verification tokens, AES-256 field-level transaction encryption, and custom DNS zone records (DKIM, SPF, DMARC) with Resend API integration for high-deliverability transactional emails. Deployed with serverless 2nd-gen Firebase Cloud Functions.

⚛️ React 18 + Vite 🔌 Socket.io 🟢 Node.js & Express 🍃 MongoDB Atlas 🤖 Ollama (Gemma2) 🔥 Firebase Functions 🔒 AES-256 Encryption
